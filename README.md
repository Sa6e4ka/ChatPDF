# PDF AI Assistant Bot

### This Telegram bot allows users to upload PDF files and interact with their content through AI-powered analysis. Users can ask questions about the document, and the bot provides relevant answers based on its contents.

## Features

PDF Upload & Processing – Users can upload PDFs for AI-based content extraction.

AI-Powered Q&A – Ask questions about the document, and the bot provides accurate responses.

Quick & Efficient – Get instant insights without manually searching through the text.
